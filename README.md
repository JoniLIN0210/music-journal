# 听歌手记 · Music Journal

- `index.html`：日常音乐数据记录页，分三部分：I 画像（艺人、年代）/ II 歌（Top 100）/ III 这些年（红心时间线、歌单），最后是最近七天
- `2026/index.html`：2026 年度报告（主页的子页面，地址 /2026/）（A/B 面十轨 + 封底曲目表）
- `fetch_data.py`：刷新数据 → `data/music.js`
- `data/listen2026.js`：网易云月度听歌报告（时长、年历、时段、深夜、每月主打），需登录态，由 Claude 在已登录的浏览器里读取
- `data/playcounts.json`：登录态才拿得到的精确播放次数（可选，缺失时按 score 估算）

刷新：

    python3 fetch_data.py

设计方向（v2）：纯黑白 + 粗体窄无衬线（Archivo），颜色只来自你的专辑封面。
年度报告每一章的底色，从那一章主角的封面里自动取色。
参考：NTS、Warp、ECM、XL Recordings 官网，以及 Apple Music 的封面取色。

## v3 · 唱片元素
把整个网站当成一张唱片来做，只用黑白与封面原色：
- 回到顶部：小黑胶（`assets/record.js`），随滚动转动，外圈是阅读进度，中心标签是第一名 / 年度之歌的封面。
- 年度报告分 Side A / Side B（A1–A5、B1–B5），中间有一段"翻面"；封面写目录号 JL–2026 · 33⅓ RPM。
- 每月听歌的脉冲叠线图（参考 Joy Division《Unknown Pleasures》封面）。
- 年度之歌：唱片从封套里滑出，按 33⅓ 转旋转。
- 红心曲目单按 liner notes 写法给出每首时长和总时长；主页 Top 100 也加了时长。
- 主页歌单悬停时唱片从封套里抽出一截；顶栏的均衡器表示“正在听”。

## v11 · 统一口径（参考 Last.fm / stats.fm / Spotify Wrapped）
- 每部分标题右边固定写三行：时间 · 来源 · 算法。
- 歌：唱片箱 = 所有时间播放次数前 20；完整榜单可切换“所有时间 / 最近一周 / 2026 每月”三种时间范围（网易云能给的三种口径），并说明为什么最多 100 首；第二层按艺人筛选（这个榜上 2 首及以上，最多 8 位）。发行年代移到“这些年”，“有唱片内页”只作为标签。
- 人：前十位标明“所有时间”；新增“2026 每个月最常听的艺人”（听歌月报，柱子 = 那个月听 TA 的分钟数，重复上榜的人加黑）。
- 此刻：只留最近一周前 5 首和一句话，“看完整榜单”直接切到上面的“最近一周”。

## v10 · 首屏改成一张唱片封面
- 去掉“一句话”大段文字。首屏像一张唱片的正面：右边是第一名的封套，黑胶从封套里滑出一半在转；左边只有 13,840（计数器滚到位）和一行小字；底部四条像封底署名的事实（循环最多 / 最常回到 / 红心最多的一年 / 一共听了多久）。
- 入场：封套从右边滑进来，黑胶再滑出、从静止慢慢转起来，署名逐条浮现。往下滚：黑胶越转越快、继续往外滑，整张唱片往上飘；鼠标移动时唱片轻轻偏转。数字压在黑胶上的部分反白。
- 手机上封套在上、数字在下，署名两列。

## v9 · 每部分一个“为它而做”的动效
- 首屏：13,840 像机械计数器一样逐位滚到位；一句话逐句浮现。
- I 歌：唱片箱（滚动翻、停下黑胶滑出）。
- II 人：前十位艺人的占比条依次长出来。
- III 这些年：时间隧道。整屏变黑钉住，往下滚就沿着时间往前走，每一年点下的红心封面从远处迎面飞过，中间是那一年的大字和“几颗红心 · 第一颗是哪首”；空白的年份几乎没有封面。只移动“镜头”一层，实测 60 帧不掉帧。之后是可以点开每一年的柱状时间线。
- 全页：每部分开头那句大字随滚动一句一句亮起来；每部分标题滑入。
- “减少动态效果”时全部退回静态；数据不足两年时不显示时间隧道。

## v8 · 主页重新梳理：一条线，四个问题
- 问题：“最常听的歌”在页面上出现了四次（旋转圆筒、第一名特写、唱片箱、Top 100 列表），顺序还是“歌 → 艺人 → 歌”，看不出每块为什么存在。
- 现在：首屏回答“你是怎样的听众”，然后由近到远四个问题，每个问题只用一种呈现：
  - I 歌 · 你反复按下的歌：唱片箱（前 20 首，滚动翻、停下黑胶自己滑出来，像在放这首歌；第一张就是第一名，信息里写“加起来多少小时”）→ 完整的 100 首（可筛选）→ 全部唱片内页目录。
  - II 人 · 你反复回到的人：播放最多的艺人特写 + 前十位占比。
  - III 这些年 · 你一路收下的歌：红心时间线（点一年展开）→ 这些歌来自哪个年代 → 从红心里抽一首 → 其他歌单。
  - IV 此刻 · 这一周你在听什么 → 年度报告。
- 每部分结尾有一行“Next”：用一句事实把下一部分接上，点一下滚过去；下一部分没有数据时自动接到再往后一部分。
- 去掉了旋转圆筒和第一名特写；平滑滚动和唱片箱保留在 `assets/stage3d.js`。

## v5 · 年度报告打磨
- 封面之后加“封底式目录”：Side A / Side B 十章，每章一个要点数字，点一行跳到那一章。
- 右侧章节导航悬停时显示章节名；有章节因数据不全被拿掉时，A/B 编号和“翻面”页自动重排。
- “最长的一天”并入年历一章（年历上的外框就是这两天）；年历悬停 / 点一天显示日期和时长。
- 每月叠线图：本月没过完，线停在最后一天，不再垂直掉到底。
- 年度卡片：目录和封底各有一个按钮，在浏览器里用 canvas 画一张 1080×1350 的 PNG（年份、每日波形、四个数字、年度之歌、年度艺人），可下载或长按保存，不上传。统计事件 `event/card`、`event/card-download`。

## 给别人用：make/
分享链接：https://jonilin0210.github.io/music-journal/make/
1. 访客把页面上的“听歌手记”书签拖到书签栏；
2. 在已登录的 music.163.com 点书签 → `make/collect.js` 在他自己的浏览器里读取数据（排行、歌单、红心、月报）；
3. 数据 gzip 压缩后放在网址 `#` 后面打开 `make/receive.html`（`#` 后的内容不会发给服务器），存进 localStorage，跳转到 `/?me` 和 `/2026/?me`。
- `assets/source.js`：带 `?me` 时改读本地数据；转义字符串、只放行网易云图床；左下角提供下载单文件 / 重新生成 / 清除。
- 页面每个章节独立渲染，数据不全的章节自动隐藏。
- 统计：`assets/stats.js` 里填 GoatCounter 站点代码。记录页面访问（访客本地页面记在 `/me/...` 下）和事件：`event/generated`（生成次数）、`event/bookmark-drag`、`event/download`。不记录任何听歌数据。

## 唱片内页 Liner Notes
点开 Top 100 里的任意一首、榜上的艺人、时间线里的红心，或 Part II 底部“全部唱片内页”目录里的条目，从右边抽出一页“内页”。
- `data/credits.js`：`python3 fetch_credits.py` 生成。网易云公开接口里的署名（作词/作曲/编曲/制作，取自歌词开头的署名行，不保存歌词）、专辑发行时间与厂牌、艺人照片与作品数。
- `data/notes.js`：手写的背景笔记（5 位艺人、6 首歌、3 张专辑）。由公开资料整理、交叉核对后重写；只有单一来源或只见于搜索摘要的说法已删除或在 `caveat` 中注明；每条附资料来源。
- `assets/liner.js`：抽屉组件。任何带 `data-note="song:ID"` / `artist:名字` / `album:专辑名` 的元素都能点开；支持 `#notes/...` 直达、Esc 关闭、←/→ 翻页。访客本地版本不启用。

## 背景音乐
`assets/music.js`：勃拉姆斯《第三交响曲》第三乐章 Poco allegretto（在红心列表里），接第二乐章 Andante，循环。
录音为 Musopen Symphony Orchestra，CC0 公有领域，直接引用 Wikimedia Commons 上的文件（优先 MP3 转码，失败时用原始 OGG）。
浏览器不允许有声自动播放：能播就淡入，不能就等第一次点击或按键；暂停会记住（localStorage `mj:music`），切换页面时从原位置接着放（sessionStorage）。
